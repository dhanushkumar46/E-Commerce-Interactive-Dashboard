# 🛒 E-Commerce Interactive Dashboard

An interactive dashboard for analyzing e-commerce sales data and visualizing business insights using Python and Plotly.

## 📌 Project Overview

The E-Commerce Interactive Dashboard is a data visualization project developed using Python and Plotly. It analyzes online retail sales data and presents meaningful business insights through interactive charts and Key Performance Indicators (KPIs).

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Identify monthly revenue trends.
- Understand product performance.
- Analyze country-wise revenue distribution.
- Explore product price distribution.
- Visualize relationships between sales-related variables.

## 📊 Dataset Information

**Dataset:** Online Retail Dataset

| Description | Value |
|---|---:|
| Total Records | 524,878 |
| Total Transactions | 19,960 |
| Total Products | 3,922 |
| Total Customers | 4,338 |
| Total Countries | 38 |
| Total Revenue | 10,642,110.80 |

## 📈 Dashboard Visualizations

The dashboard includes five types of visualizations:

1. **Line Chart** – Monthly revenue trends.
2. **Bar Chart** – Top 10 products.
3. **Donut Chart** – Country-wise revenue distribution.
4. **Histogram** – Product price distribution.
5. **Heatmap** – Relationships between sales-related variables.

## ⚡ Interactive Features

- Country dropdown filter.
- Interactive hover information.
- Zoom and pan functionality.
- KPI cards for important business metrics.
- Interactive chart exploration.
